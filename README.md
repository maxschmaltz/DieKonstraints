# LaSTing

This branch stores general materials for the LaSTing priority program. This includes slides, posters, etc. for and from LaSTing get-togethers, conferences, spring/fall schools etc. You can find more information about LaSTing on its [website](https://www.lasting-spp.org).


### Kick-off Meeting, October 8-9, 2026

The materials for the first annual LaSTing conference are stored in the [kickoff_oct26](kickoff_oct26) directory. This includes the [3-minute pitch](kickoff_oct26/pitch) and the [poster](kickoff_oct26/poster). The details about the event are given in the [handbook](kickoff_oct26/handbook.pdf) (online version [here](https://www.lasting-spp.org/assets/handbook.pdf)). There are also [notes](kickoff_oct26/notes.md) on the event available (private version only).
